GeoVac · Papers

Hamiltonian downloads

Each Hamiltonian is given two ways: its one- and two-electron integrals as an FCIDUMP file, which classical chemistry codes read directly, and its qubit form after the Jordan-Wigner mapping, as a list of Pauli strings with coefficients in hartree. Every number on this page is read from the metadata file next to it, written by a script that checks it against the paper.

Lithium hydride (LiH), GeoVac composed builder

Papers 14 and 17; library entry hamiltonian('LiH')

composed hydrogenic blocks at the library defaults (max_n = 2), with the Phillips-Kleinman core term. 30 qubits; 838 Pauli terms (identity included); 1-norm 27.7 Ha (identity excluded).

The same Hamiltonian the site's qubit-resource dashboard shows (the dashboard's 1-norm includes the constant identity term; the figure here leaves it out). Matched qubits, not matched accuracy: the composed builder is a fast, cheap estimator (Paper 17 documents its accuracy).

  • lih_composed.fcidump (5 kB): FCIDUMP integrals (Knowles-Handy; reads into PySCF, Block2, Molpro)
  • lih_composed_pauli.txt.gz (4 kB): qubit Hamiltonian, one Pauli string per line (gzip text)
  • lih_composed.json (1 kB): metadata (counts, energies, conventions)

Built by benchmarks/build_site_downloads.py; checks: Pauli count 838 (identity included) and 1-norm 27.715 Ha against the numeric registry; FCIDUMP read back.

Water (H2O), Slater DZP basis, frozen-core

Paper 62 (papers/group2_quantum_chemistry/paper_62_water_equal_size_slater.tex), Table tab:resources

Slater DZP, 24 functions; O exponents set on the free atom, polarization set on water (Paper 62). 46 qubits; 107,382 Pauli terms (identity included); 1-norm 706.3 Ha (identity excluded); frozen-core CCSD(T) energy -76.281739 Ha.

Not a GeoVac lattice Hamiltonian: tuned exponential functions in a standard molecular-orbital encoding (Paper 62).

  • water_slater_dzp_fc.fcidump (472 kB): FCIDUMP integrals (Knowles-Handy; reads into PySCF, Block2, Molpro)
  • water_slater_dzp_fc_pauli.txt.gz (948 kB): qubit Hamiltonian, one Pauli string per line (gzip text)
  • water_slater_dzp_fc.json (1 kB): metadata (counts, energies, conventions)

Built by benchmarks/export_paper62_water_hamiltonian.py; checks: Pauli count by two routes (closed form, explicit operator) = 107,382; 1-norm 706.3 Ha; fc-CCSD(T) -76.281739 Ha; FCIDUMP read back bit-close.
