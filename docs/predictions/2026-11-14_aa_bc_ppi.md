## Object

Slater functions, AB's two geometries: B at the origin, C at (0, 0, D1), A at D2 (sin g, 0, cos g), x = cos g,
sin g >= 0.

    PX = (1s_A 1s_A | 1s_B 2px_C),   2px_C = sqrt(zC^5/pi) x e^{-zC rC},

the p function in the ABC plane, perpendicular to BC, pointing to A's side. Cases A1 (D1 = 9/5, D2 = 13/5,
zB = 13/10, zC = 1, zA = 9/10) and A2 (3/2, 12/5, 1, 6/5, 4/5); referee points x = 1/2 (A1), -1/3 (A2).

**Exact reduction (derived, not computed).** rho_BC = N e^{-zB r} r sin(theta) cos(phi) e^{-zC s}. By the
addition theorem only the m = 1 term survives, and with the orthogonality of P_L^1 the factorials cancel:

    PX = sum_{L >= 1} G_L P_L^1(x),   P_L^1(x) = sqrt(1 - x^2) P_L'(x)   (no Condon-Shortley phase),

where G_L has AB's form, 4 pi/(2L+1) int r^2 rho^1_L v_L dr, v_L the multipole of the 1s potential V_A (AB's
kernel NA - Y + zA dY, unchanged), and the m = 1 density multipole follows from
sqrt(1 - t^2) P_L^1(t) = L(L+1)/(2L+1) (P_{L-1} - P_{L+1}):

    rho^1_L = N e^{-zB r} r [ d_{L-1}/(2L-1) - d_{L+1}/(2L+3) ],   d_k the Legendre coefficients of e^{-zC s}.

In AB's engine normalization (density(k) = d_k/(2k+1)) the engine input is r (dens_{L-1} - dens_{L+1})/(2L+1).
No D1 term (x is the same coordinate about B and about C). Normalization 2 sqrt(zB^3 zC^5), as PC's.

## Predictions (none uses an exact split, a constant set or a decay exponent of PX)

- **AQ0 (engine self-checks, run first).** (i) The extended engine still reproduces AB's coefficients key for key
  (Q and mod 2^61 - 1, L <= 30) through its unchanged path. (ii) Per channel, G_L at L = 1, 3, 7 (both cases)
  equals an independent quadrature of rho^1_L against V_A's multipole (no kernel split) to relative 1e-18 at 22
  digits. This checks the engine against the reduction formula, not the reduction itself; P1 checks the reduction.
  Falsifier: either fails. Probability 0.9.
- **P1 (exact value).** The exact split at 2000 digits, summed to L = 240 against P_L^1 at the referee point,
  matches R2's stated value to <= 2e-10 in both cases (P1a), and at the third points (P1c: A1 x = 0, A2 x = 0.8)
  to <= 2e-10. Two points per case catch a reduction error that varies smoothly with L. R1's finest grid is
  reported against a loose 1e-8 and is not part of P1. Probability 0.85.
- **P2 (constant set; only P2a scored).** Mod both primes (2^61 - 1, 4611686018427387847), L <= 1000:
  (P2a) the set of constants with nonzero coefficient in G_L is the same at every L >= 2. Probability 0.85.
  L = 1 is excluded because its density uses d_0, whose radial form is the one AB's set did not stabilise at
  (AB: fixed from L = 2). Reported, not scored, because AP's results imply them (PC's density is built from the
  same r-shifted d_{L+-1} terms and used exactly AB's 21 keys): the set lies inside AB's 29-key candidate set C,
  no gamma, and whether it is exactly AB's 21. P2a is live only against a cancellation that changes keys with L.
- **P3 (decay; the live clause).** In AB's instrument (beta_eff(L) = log|G_{L+1}/G_{L-1}| / log((L+1)/(L-1)) on
  G_L / rho^L, exact G_L at 2000 digits, L <= 240), **beta_eff(220) lies in [-5.35, -5.0] in both cases**, with
  one sign of G_L for L >= 20. Reason: the cusp of the p density at C, x r_C, transforms like k_x k^-6; against
  V_A (k^-6) it gives a non-analytic part proportional to a_x |a|^7, a = A - C, a_x = D2 sin g, nonzero at x*.
  So PX keeps AB's (x* - x)^{7/2} branch. For any function with that branch, the P_L^1 coefficients decay one
  power faster than the P_L ones (PX = sqrt(1 - x^2) H', H = sum G_L P_L carries 9/2), so beta -> -5; the toy T
  puts beta_eff(220) at -5.180 (A1) and -5.143 (A2), and the band is T +- about 0.17. What P3 tests: that the
  coefficient of a_x |a|^7 does not cancel (the factor sin g is analytic at x* and cannot move the branch; the
  shift by one is calculus, checked by T). If it cancelled, the next branch would be 9/2 (beta near -6 here).
  Surviving 5/2 or 3/2 branches would give beta near -4 or -3. Probability 0.75.

**Reported, not scored:** beta_eff at L = 20, 40, ..., 220; signs of G_L for L >= 5; whether the set equals AB's 21.
